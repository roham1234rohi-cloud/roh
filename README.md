# PROJECT: ROHI
Your life. Your system. Your rules.

Frontend-only, offline-capable PWA. No build step, no dependencies, data in localStorage.

## Run locally
`npx serve .` (or any static server; service worker needs http://localhost)

## Deploy on Netlify (free)
Drag the `rohi` folder onto app.netlify.com/drop — or connect the repo with build command empty, publish directory `.`.

## Data
Everything lives in this browser only (unencrypted). Use Settings → Export for backups.
